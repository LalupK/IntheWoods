# Overview
In the Woods is built around [url=https://www.nexusmods.com/skyrimspecialedition/mods/60888]Requiem[/url], overhauling Skyrim to create a challenging, unlevelled world with meaningful choices. If you have never played [url=https://www.nexusmods.com/skyrimspecialedition/mods/60888]Requiem[/url] before, I highly recommend you watch the introductory [url=https://www.youtube.com/watch?v=fG7D8meR0cY]video[/url] by [url=https://www.youtube.com/@GreedGaming01]Greed[/url]. In the Woods contains the latest version of [url=https://www.nexusmods.com/skyrimspecialedition/mods/60888]Requiem[/url], complemented by [url=https://www.nexusmods.com/skyrimspecialedition/mods/61342]Minor Arcana[/url], [url=https://www.nexusmods.com/profile/SUNNY333456/mods?gameId=1704]Sunny's[/url] [url=https://www.nexusmods.com/skyrimspecialedition/mods/42633]Small Tweaks[/url], and [url=https://www.nexusmods.com/skyrimspecialedition/mods/42591]Noxcrab's Tweaks[/url].

I was motivated to create In the Woods as a spiritual successor to the [url=https://wildlandermod.com/]Wildlander[/url] but have taken inspiration from many others, such as [url=https://www.nexusmods.com/games/skyrimspecialedition/collections/qdurkx]Gate to Sovngarde[/url] and [url=https://github.com/Fornication/Arkays-Commandment]Arkay’s Commandment[/url]. Admittedly, this list has been developed over several years, taking breaks, returning with modding breakthroughs, and using whatever passion I have left to finish something that is worthwhile sharing. Over time, it has morphed into my personal modlist, with its own vision and preferences.

There will surely be plenty of bugs, both modded and vanilla in origin, that I have yet committed time to address. A lot of time has already gone into patching, testing, and reviewing the modlist. With its public release, I’m hopeful that issues can be better documented and prioritised.

View the full load order [url=https://loadorderlibrary.com/lists/in-the-woods]here[/url]. Considering the size of the list and its lack of new content, In the Woods contains many small mods that contribute to the overall experience. In the Woods requires an English installation of the latest Skyrim Special Edition version through Steam and the Anniversary Edition DLC.
