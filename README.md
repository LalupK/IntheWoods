# Overview
In the Woods is a Wabbajack modlist providing an immersive, survival, role-playing experience. Containing 3000 mods, In the Woods strives to preserve Skyrim's original feeling while remaining relatively performance-conscious. The list requires the Anniversary Upgrade and integrates its content where appropriate.
